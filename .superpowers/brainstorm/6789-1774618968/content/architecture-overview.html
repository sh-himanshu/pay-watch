Data Flow
1. Vercel Cron → triggers Email Scanner every 15 min
2. Email Scanner → fetches new mail via Gmail API
3. Parsing Pipeline → Rules match first, LLM fallback for unknowns
4. Fee Detection Engine → compares against historical data in Supabase
5. Notification Dispatcher → sends push / email based on urgency + user prefs
6. Dashboard → reads from Supabase (real-time subscriptions for live updates)
